# MITRE ATT&CK 批量测试脚本使用手册

## 概述

`run_all_atomics.ps1` 是一个用于在 Windows 环境下批量执行 MITRE ATT&CK 原子测试的 PowerShell 脚本。该脚本兼容 Windows Server 2016/2019 和 Windows 10/11 操作系统。

---

## 系统要求

### 操作系统
- Windows Server 2016
- Windows Server 2019
- Windows Server 2022
- Windows 10
- Windows 11

### 软件依赖
- PowerShell 5.0 或更高版本
- `goart-windows.exe`（主执行程序）
- （可选）Atomic Red Team 项目

---

## 安装部署

### 1. 目录结构

```
basforwindows/
├── run_all_atomics.ps1    # 主脚本
├── goart-windows.exe      # 执行程序（必需）
├── logs/                  # 日志目录（自动创建）
├── reports/               # 报告目录（自动创建）
├── configs/               # 配置目录（自动创建）
└── 使用手册.md            # 本文档
```

### 2. 准备工作

```powershell
# 1. 确保脚本有执行权限
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 2. 将 goart-windows.exe 放到脚本同目录下

# 3. （可选）克隆 Atomic Red Team 项目
git clone https://github.com/redcanaryco/atomic-red-team.git "C:\AtomicRedTeam\atomic-red-team"
```

## 命令行参数

| 参数 | 别名 | 说明 | 默认值 |
|------|------|------|--------|
| `-Help` | `-h`, `-?` | 显示帮助信息 | - |
| `-TechniqueId` | `-t` | 指定要测试的技术ID | - |
| `-Category` | `-c` | 按类别运行测试 | - |
| `-ListFile` | `-l` | 从文件读取技术列表 | - |
| `-SkipFailed` | `-s` | 跳过失败的测试继续执行 | $false |
| `-DryRun` | `-d` | 干运行模式（仅显示不执行） | $false |
| `-Verbose` | `-v` | 显示详细输出 | $false |
| `-MaxParallel` | - | 最大并行进程数 | 1 |
| `-Timeout` | - | 单个测试超时时间（秒） | 300 |
| `-Index` | - | 指定测试索引号 | - |

## 使用示例

### 基本用法

```powershell
# 显示帮助信息
.\run_all_atomics.ps1 -Help

# 运行所有测试
.\run_all_atomics.ps1

# 干运行模式（预览将要执行的测试）
.\run_all_atomics.ps1 -DryRun
```

### 测试特定技术

```powershell
# 测试单个技术
.\run_all_atomics.ps1 -t T1059

# 测试子技术
.\run_all_atomics.ps1 -t T1021.004

# 测试特定技术的指定索引
.\run_all_atomics.ps1 -t T1059 -Index 1

# 详细输出模式
.\run_all_atomics.ps1 -t T1059 -Verbose
```

### 按类别测试

```powershell
# 运行执行类测试
.\run_all_atomics.ps1 -c execution

# 运行持久化测试
.\run_all_atomics.ps1 -c persistence

# 运行权限提升测试
.\run_all_atomics.ps1 -c privilege-escalation

# 运行防御规避测试
.\run_all_atomics.ps1 -c defense-evasion
```

### 从文件读取测试列表

```powershell
# 从配置文件读取
.\run_all_atomics.ps1 -l techniques.txt

# 配合并显示详细信息
.\run_all_atomics.ps1 -l techniques.txt -Verbose
```

### 高级用法

```powershell
# 设置超时时间为600秒
.\run_all_atomics.ps1 -t T1059 -Timeout 600

# 跳过失败的测试继续执行
.\run_all_atomics.ps1 -l techniques.txt -SkipFailed

# 组合参数使用
.\run_all_atomics.ps1 -c execution -SkipFailed -Verbose -Timeout 600
```

## 错误处理

### 常见错误及解决方案

| 错误信息 | 原因 | 解决方案 |
|----------|------|----------|
| `goart-windows.exe 未找到` | 执行程序不在脚本目录 | 将 goart-windows.exe 复制到脚本同目录 |
| `配置文件不存在` | 指定的配置文件路径错误 | 检查文件路径是否正确 |
| `无法解析技术ID` | 技术ID格式不正确 | 使用正确的格式如 T1059 或 T1021.004 |
| `测试超时` | 测试执行时间超过设定值 | 使用 -Timeout 参数增加超时时间 |
| `未知类别` | 指定的类别名称错误 | 使用支持的类别名称 |

### 执行策略错误

如果遇到执行策略限制：

```powershell
# 方法1：临时绕过
PowerShell -ExecutionPolicy Bypass -File .\run_all_atomics.ps1

# 方法2：修改当前用户执行策略
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 方法3：解除脚本签名要求
Set-ExecutionPolicy -ExecutionPolicy Unrestricted -Scope CurrentUser
```

## 高级配置

### 修改默认路径

编辑脚本中的以下变量：

```powershell
$script:GOART_PATH = Join-Path $script:BASE_DIR "goart-windows.exe"
$script:LOG_DIR = Join-Path $script:BASE_DIR "logs"
$script:REPORT_DIR = Join-Path $script:BASE_DIR "reports"
$script:ATOMICS_PATH = "C:\AtomicRedTeam\atomic-red-team"
```

### 修改默认超时时间

```powershell
$script:TIMEOUT = 300  # 默认300秒
```

### 添加自定义技术类别

在 `Get-TechniquesByCategory` 函数中添加：

```powershell
"your-category" {
    return @("T1001", "T1002", "T1003")
}
```

## 安全注意事项

1. **测试环境**：建议先在隔离的测试环境中运行
2. **权限要求**：部分测试可能需要管理员权限
3. **日志记录**：测试会生成日志，注意保护敏感信息
4. **生产环境**：谨慎在生产环境执行测试
